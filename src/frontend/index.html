    Guía del sistema

    Problema del camino mínimo | Algoritmo de Dijkstra

    ¿Qué hace esta aplicación?

    Objetivo

    Permite trabajar el problema del camino mínimo mediante un grafo dirigido ponderado con pesos positivos, configurando conexiones unidireccionales, bidireccionales y ciclos.

    Generación

    El usuario puede generar el grafo aleatoriamente (simulando la topología de una red informática con pesos entre 10 y 30) o construirlo y modificarlo manualmente de forma gráfica y mediante formulario.

    Algoritmo

    El algoritmo de Dijkstra puede ejecutarse paso a paso o hasta completar la búsqueda de todos los caminos mínimos posibles entre el origen y el destino.

    Cómo utilizar el sistema

    1. Cantidad de nodos

    Ingrese un número entero entre 7 y 16.

    2. Tipo de grafo

    Seleccione Aleatorio (con casillas opcionales para Bidireccional y Ciclos) o Manual.

    3. Crear o modificar grafo manual

    En modo manual puede hacer clic directamente sobre dos nodos en el lienzo o usar el cuadro superior para agregar conexiones, editar pesos y alternar bidireccionalidad (se permiten nodos aislados o subgrafos desconectados tipo isla). Una vez confirmado, puede usar el botón Modificar grafo para editarlo (reiniciando Dijkstra automáticamente).

    4. Origen, Destino y Ejecución

    Seleccione los vértices de origen y destino, presione Inicializar y avance con Siguiente paso o Ejecutar todo. Si cambia el Origen o el Destino después de una ejecución previa, Dijkstra se reinicializará automáticamente.

    5. Herramientas de visualización

    Inicio restablece la vista completa; Anterior y Siguiente recuperan vistas previas; Mover desplaza el lienzo; Zoom amplía una región seleccionada; PNG y SVG exportan el gráfico.

    Dijkstra paso a paso

    Inicio

    El vértice origen recibe distancia 0 ([0, -]_0). Los demás vértices comienzan con distancia infinita ([∞, -]_0).

    Selección

    En cada iteración se selecciona el vértice no procesado con la menor distancia acumulada finita.

    Relajación y Comparación

    Para cada arista saliente u → v con peso w, se calcula L(v) = L(u) + w. Si es menor que la etiqueta actual, se actualiza; si es igual, se registra un predecesor óptimo alternativo; si es mayor, se conserva la etiqueta anterior.

    Finalización

    El proceso termina cuando todos los vértices alcanzables desde el origen han sido procesados (los vértices con distancia ∞ quedan identificados como inalcanzables), mostrando en la esquina superior derecha el cuadro resaltado con todos los caminos mínimos hallados.

    Etiquetas y conceptos

    Notación [L, X]_k

    L representa la distancia acumulada, X es el vértice predecesor inmediato y k es la iteración en la que se generó la etiqueta.

    Predecesores alternativos y Caminos mínimos

    Cuando dos o más rutas alcanzan un vértice con la misma distancia mínima, el sistema conserva todos los predecesores óptimos para reconstruir todos los caminos mínimos existentes.

    Etiqueta tachada y código de colores

    En el historial, las etiquetas reemplazadas por una distancia menor aparecen tachadas. Los colores identifican en todo momento el nodo en evaluación (amarillo), etiquetas recién mejoradas (azul), origen (verde), procesados (celeste), en frontera (violeta) y destino alcanzado (naranja).
